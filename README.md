# Flutter Desktop App (Windows)

## Requisitos

1. Flutter instalado (cualquier versión).  
2. Visual Studio Community con la carga de trabajo "Desktop development with C++".

## Instalar FVM

flutter pub global activate fvm

Agregar al path: C:\Users\Users\AppData\Local\Pub\Cache\bin

 ## Dentro del proyecto

fvm use

flutter run
